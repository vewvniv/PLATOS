# ADRs

Um ADR é uma decisão arquitetural permanente e curta.

Regras:
- Numere sequencialmente: `0001-...md`.
- Uma decisão por ADR.
- Não altere silenciosamente um ADR já aceito.
- Para mudar uma decisão, crie um novo ADR que substitua o anterior.
- O ADR deve apontar para a seção correspondente da arquitetura quando útil.
- Não replique implementações; registre contexto, decisão e consequências.

O SAD v3 lista D1–D52 como decisões aceitas e D2 como rejeitada, e determina que mudança dessas decisões exige novo ADR.
